# Intelligent Email Categorization System

## Features
- 4 categories: Work, Personal, Spam, Finance
- 100% accuracy on test set
- Web interface for easy use
- Batch processing support

## Installation
```bash
pip install -r requirements.txt
python main.py  # Train model
streamlit run app.py  # Launch web app

Usage
Open web browser at localhost:8501

Enter email text or upload CSV

Get instant category prediction
